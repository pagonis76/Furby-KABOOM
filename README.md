# Furby-KABOOM
app for 2012 furbies and furby booms, this app is compatible with both and has been tested with all personalities and with five different furbies
[click here to try it!](https://pagonis76.github.io/Furby-KABOOM/)
it is recommended to have your volume at ATLEAST 50-60% for your furby to hear the signals!

# how to open the .pmp (raw file)?
use [Penguin mod](https://penguinmod.com/) to open the raw file, there, you can edit it all you want, maybe add new things :D
